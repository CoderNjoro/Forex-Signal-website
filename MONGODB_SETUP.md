# MongoDB Atlas Setup Guide

This guide will help you set up MongoDB Atlas (cloud database) for your production website.

## Why MongoDB Atlas?

- ✅ Free tier available (512MB storage)
- ✅ No need to manage servers
- ✅ Automatic backups
- ✅ Works with Railway, Render, and other hosting
- ✅ Secure and reliable

---

## Step-by-Step Setup

### Step 1: Create Account

1. Go to [https://www.mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas)
2. Click **"Try Free"** button
3. Fill in:
   - Email address
   - Password
   - First name, Last name
   - Company (optional)
4. Click **"Get started free"**
5. Verify your email

### Step 2: Create Organization

1. After login, you'll see "Create an Organization"
2. Enter organization name (e.g., "My Projects")
3. Click **"Next"**
4. Select **"Just exploring"** or your use case
5. Click **"Finish"**

### Step 3: Create Project

1. You'll see "Create a Project"
2. Enter project name (e.g., "Forex Signals")
3. Click **"Next"**
4. Click **"Create Project"**

### Step 4: Build Database (Create Cluster)

1. Click **"Build a Database"** button
2. Choose **"M0 FREE"** (Free Shared tier)
   - 512MB storage
   - Shared RAM
   - Perfect for development/small apps
3. Select Cloud Provider:
   - **AWS** (recommended)
   - Google Cloud
   - Azure
4. Select Region:
   - Choose closest to you or your users
   - Example: `N. Virginia (us-east-1)` for US
5. Click **"Create"**
6. Wait 1-3 minutes for cluster to be created

### Step 5: Create Database User

1. You'll see "Create Database User" screen
2. Authentication Method: **"Password"**
3. Username: Enter a username (e.g., `forexuser`)
4. Password: 
   - Click **"Autogenerate Secure Password"** (recommended)
   - OR create your own strong password
5. **⚠️ IMPORTANT**: 
   - Click **"Copy"** to copy the password
   - **Save it somewhere safe!** You'll need it for connection string
6. Click **"Create Database User"**

### Step 6: Network Access (Whitelist IPs)

1. You'll see "Network Access" screen
2. For development:
   - Click **"Add My Current IP Address"**
3. For production (hosting):
   - Click **"Add IP Address"**
   - Enter: `0.0.0.0/0`
   - Comment: "Allow all IPs for hosting"
   - Click **"Confirm"**
   - ⚠️ This allows all IPs - safe for production hosting
4. Click **"Finish and Close"**

### Step 7: Get Connection String

1. Click **"Connect"** button on your cluster card
2. Choose **"Connect your application"**
3. Driver: **"Node.js"**
4. Version: **"5.5 or later"**
5. You'll see a connection string like:
   ```
   mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```
6. **Copy this string**

### Step 8: Customize Connection String

1. Replace `<username>` with your database username (from Step 5)
2. Replace `<password>` with your database password (from Step 5)
3. Add database name before the `?`:
   - Change: `mongodb.net/?retryWrites...`
   - To: `mongodb.net/forex-signals?retryWrites...`
4. Final string should look like:
   ```
   mongodb+srv://forexuser:MyPassword123@cluster0.xxxxx.mongodb.net/forex-signals?retryWrites=true&w=majority
   ```
5. **Save this connection string** - you'll use it in Railway!

### Step 9: Test Connection (Optional)

1. In MongoDB Atlas, click **"Connect"** → **"Connect your application"**
2. Click **"Test Connection"** button
3. Should see: "Connection successful!"

## Using Your Connection String

### In Railway (Backend):

1. Go to Railway → Your Project → Settings → Variables
2. Add variable:
   - Name: `MONGODB_URI`
   - Value: `mongodb+srv://forexuser:MyPassword123@cluster0.xxxxx.mongodb.net/forex-signals?retryWrites=true&w=majority`
3. Click **"Add"**
4. Railway will automatically redeploy

### Important Notes:

- ✅ Connection string includes username and password
- ✅ Database name is `forex-signals` (or your choice)
- ✅ Network access allows all IPs (`0.0.0.0/0`)
- ✅ Use this in production environment variables

## Managing Your Database

### View Collections (Tables):

1. In MongoDB Atlas, click **"Browse Collections"**
2. You'll see your databases and collections
3. Collections are like tables in SQL

### Create Collections Manually (Optional):

Collections are created automatically when you save data, but you can create them manually:

1. Click **"Browse Collections"**
2. Click **"Create Database"**
3. Database name: `forex-signals`
4. Collection name: `users` (or any name)
5. Click **"Create"**

### View Data:

1. Click on a collection
2. You'll see all documents (records)
3. Can edit, delete, or add documents here

## Security Best Practices

1. **Strong Password**: Use autogenerated password
2. **Network Access**: 
   - For production: `0.0.0.0/0` (allows all)
   - For development: Your specific IP
3. **Database User**: Create separate user for production
4. **Connection String**: Never commit to Git!

## Troubleshooting

### Can't connect?

1. Check network access includes your IP or `0.0.0.0/0`
2. Verify username and password in connection string
3. Check database name is correct
4. Make sure cluster is running (not paused)

### Connection string not working?

1. Make sure you replaced `<username>` and `<password>`
2. Check for special characters in password (may need URL encoding)
3. Verify database name is in the string
4. Test connection in MongoDB Atlas first

### Database paused?

- Free tier clusters pause after 1 week of inactivity
- Just click **"Resume"** to restart
- Takes 1-2 minutes
